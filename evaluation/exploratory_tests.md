# 탐색 테스트 (평가 세트 밖 질문)

> 실행일: 2026-11-12 · 대상: 2차 평가와 같은 코드(`src/agent.py`의 `run_query`), 같은 `.env` 모델
> 1~8번: `run_query`로 한 번씩만 실행했다. ThrottlingException 없음. 질문 8에 전화번호가 있어 이 실행만 LangSmith 추적을 껐다.
> 9~10번: 사용자가 시연 화면(`http://localhost:8000`, `POST /query`)에서 직접 실행한 응답 원본으로만 판정했다 (다시 실행하지 않음).
> 판정 기준: SERVICE.md 정책 1~5 (지어내기, 출처·묶음, 단정 추천, 개인정보, 범위). 숫자·사실은 원본 데이터(`search_academies_data`, `data/academy_docs/`)와 직접 대조했다.

| 1. 지어내지 않는다 | 학원 이름·반 정보는 모두 근거에 있었다 (output_guard 확인). 하지만 **숫자 조건(수강료 필터 1번, 수강료 정렬 9번, 정원 기준 10번)을 LLM이 처리하다 틀렸다**. 지어낸 것은 아니지만 "전체를 확인했다", "오름차순", "소수정예로 확인된 곳"처럼 틀린 결과를 확신 있게 말했다 |
